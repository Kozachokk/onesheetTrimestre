# OneSheet Trimestre — Quarterly Analytics Dashboard

An executive analytics website built with **Chart.js** and **Tailwind CSS**.

## Features

- 📈 **4 Interactive Chart.js Types**:
  - **Line & Area Chart**: Realized revenue growth vs. target forecast with gradient fill and toggleable curve tension (smooth vs. linear).
  - **Doughnut Chart**: Revenue distribution by product segment with hover offsets and tooltips.
  - **Grouped Bar Chart**: Gross Sales vs. Operating Expenses (OpEx) quarterly comparison.
  - **Radar Chart**: Operational maturity scorecard across 6 dimensions.
- ⚡ **Dynamic Quarter Switching**: Switch between **Q1**, **Q2**, **Q3**, **Q4**, and **Full Year (FY)** to see live animated chart transitions and KPI updates.
- 🎲 **Interactive Data Shuffle**: Test live Chart.js transitions and animations with random dataset variations.
- 🌓 **Dark & Light Mode**: Seamless theme toggle with automatic adjustment of chart grids, tick colors, tooltips, and backgrounds.
- 🖨️ **Print & Export Ready**: Built-in clean print styles formatted for executive one-sheet reporting.

## How to Run

You can open `index.html` directly in any modern browser:

```bash
# Option 1: Open index.html directly
xdg-open index.html   # On Linux
open index.html       # On macOS

# Option 2: Run a simple local HTTP server (optional)
python3 -m http.server 3000
# Then visit http://localhost:3000 in your browser
```
